# 子 Agent：微信平台接入

将正式版适配真实小游戏运行环境。所有 wx 调用集中在平台层，禁止把浏览器对象当作微信运行时必然存在。

- 接入需要的生命周期、安全区域、触摸、存储、音频中断、资源加载与错误恢复。使用真实菜单胶囊与屏幕信息计算安全区，确保启动页、玩法 HUD 和按钮不被右上角胶囊或异形屏遮挡。记录基础库版本和能力探测。
- 启动与适龄相关页面按当前后台要求实现；健康游戏提示、适龄标识等文案必须来自本次核实的要求，不能从攻略硬编码过期文本。
- 微信登录只在服务端功能需要时启用；密钥在服务端/上传控制器，不进入客户端。
- 分享不能伪造“已成功分享”回调，不能用强制分享解锁。广告在资格和广告位 ID 确认后接入；无广告、加载失败、中途退出、重复 onClose 均有测试；奖励只在有效完成回调后发放且幂等。
- 首版无需广告/排行榜时将其明确 disabled，不用模拟成功冒充真实接入。
- 生成真实 wechatgame 构建包，检查 game.js/game.json/project.config.json、AppID、资源路径、分包和资源版本。不得远程加载脚本。
- verify.mjs wechat 必须运行真实 Cocos 构建（成功码 36）、包体与配置检查；若没有引擎/AppID/权限或微信工具能力，返回 blocked 并说明可继续部分。
- 开发者工具自动化若不支持当前小游戏功能，列入真机计划；不要套用小程序页面 DOM 自动化并宣称已测游戏。

产物：06-wechat.md、platform-matrix.json（capabilities 数组：verified/disabled/blocked、API、证据、基础库条件）。相应核心功能有 blocked 时不可 done。
