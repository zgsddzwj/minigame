# 项目默认简报

状态：待主 Agent 研究并提出候选；尚未确定具体游戏，也未开始发布。

- 制作模式：一个人决策，AI 主 Agent 管理专业子 Agent。
- 平台：微信小游戏；中文；2D；竖屏；单手操作；单局目标 1–3 分钟。
- 首版：一个可解释的核心玩法、一套主题、基础教程、完整胜负闭环、音效开关、本地存档与重开。
- 暂缓：多人实时对战、UGC、聊天、内购、复杂经济、大量剧情和重度 3D。广告只在账号资格确认后接入，必须有无广告回退。
- 首选技术：Cocos Creator 3.8 LTS 系列 + TypeScript；纯规则逻辑独立模块；微信平台适配层。具体引擎补丁、Node 和依赖版本经本机验证后锁定。
- 后端：首版离线优先，能不建则不建。确需排行榜/跨端存档时单独评审 CloudBase；不开付费资源。
- 平台 UI：竖屏界面必须适配微信右上角菜单胶囊、安全区域和常见异形屏；启动/适龄文案以真实后台要求为准。
- 美术：原创简洁几何/扁平插画，程序绘制可作为正式风格。需要位图时使用可用且获准的图像生成能力；缺能力必须报告，不假装已生成。
- 外部服务新增支出预算：0 元；使用现有 Codex 配额，耗尽则暂停，不自动购买。
- 工程目标（项目验收标准，非平台统一规定）：目标设备稳定 60 FPS，低端机至少 30 FPS；首屏可交互目标 3 秒以内；主包目标不超过 4 MB；全部以指定设备与网络的实测记录为准。
- 隐私：按功能最小化，首版不主动收集个人信息；接入微信/广告 SDK 时核对实际数据行为并更新声明。
- 首版完成标准：可重复构建、规则/流程测试通过、微信 Android 与 iOS 真机验证、无阻断问题、候选包与材料一致；“已上线”必须有真实平台发布回执。
- 人工参与：候选方向、短时试玩、视觉样张、真机验收、本人认证和平台发布决策。
- 账号信息：AppID、主体、类目、备案、资质、广告能力尚未提供。调研可继续，依赖这些信息的操作必须等待真实资料。
