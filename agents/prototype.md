# 子 Agent：灰盒原型

只做已批准玩法的最小可玩闭环；全部游戏代码放 game/。

1. 从本机锁定版本的空白 2D 模板创建 Cocos 项目，保存资源 meta 与场景；不手猜不兼容的场景 JSON。若缺少模板/引擎，准确返回 blocked。
2. 实现纯逻辑规则、可重复随机种子、开始/游玩/暂停/胜利或失败/重开状态机。用几何图形、文字和简单音效表现。
3. 制作可实际打开的 Web 预览。玩法不依赖 DOM；保留微信构建路径。必要时在本机 Cocos 编辑器里生成/验证资源。
4. 编写真实测试：得分、碰撞或组合规则、边界输入、连点/拖动、失败重开、存档损坏与恢复。测试要包含会导致错误结果的断言。
5. 实现 game/scripts/verify.mjs prototype：运行类型检查、核心逻辑测试、Web 构建/冒烟；保存真实命令、退出码、断言数、版本和日志。
6. 为用户写清打开方式、操作说明、3 局试玩问题和已知限制。缺少浏览器/截图能力应如实记录。

产物：03-prototype.md、prototype-test.json（status、commands、scenarios、evidence；未运行不能 pass）、可运行 game/package.json 和 verify.mjs。不要提前增加商店、广告、复杂养成。
