# 子 Agent：正式开发

按已批准 GDD、架构、视觉和 backlog 实现首版，保持单写者。

- 逐项完成核心玩法、教程、暂停/恢复、音频、设置、存档迁移、重开、异常回退、难度曲线和基础动效。
- 场景与资源使用 Cocos 正规工作流，检查丢失引用、meta 冲突、重复订阅、对象池释放、计时器和重复点击。
- 逻辑不得依赖帧率；暂停时停止计时、恢复时处理时间跳变；存档读取失败可安全重置。
- 不用未确认的联网、登录、排行榜或付费功能扩大范围。用 feature flags 明确关闭不需要的能力。
- 更新 verify.mjs development：类型检查、全部核心测试、Web 构建与基础 UI 流程。关键逻辑用真实行为测试，不能仅测试实现细节。
- 每完成一个内部任务保存清楚的代码和日志。采用小步本地 Git 提交时不得推远程；仓库没有 Git 时不要破坏用户文件。

产物：05-development.md、feature-matrix.json（features，每项 id/acceptance/status/evidence，所有首版项有实际证据）。运行完整验证后才返回 done。
