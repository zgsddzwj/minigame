## 0. 调研状态与诚实声明

本次会话实际尝试了联网竞品调研，结果如下（2026-10-27 实测记录）：

| 尝试 | 结果 |
| --- | --- |
| `zh.wikipedia.org`（跳一跳 / 合成大西瓜 / 羊了个羊 / Ballz 词条，WebFetch×4） | 连接超时（443 timeout 10000ms） |
| `baike.baidu.com` 三个词条（WebFetch 与带浏览器 UA 的 curl） | HTTP 403 Forbidden（反爬拦截） |
| `cn.bing.com` 检索（3 组关键词 + 1 组，curl HTTP 200） | 返回反爬占位页，无可用的真实结果摘要 |
| `developers.weixin.qq.com/minigame/introduction/guide/`（curl HTTP 200） | JS 渲染壳，纯抓取不可读，平台规则未取证 |

结论：本环境无可靠的联网取证渠道。按角色规则，**不做、也不引用任何市场数据**（用户量、收入、榜单名次一律不写）；候选改为**原创候选**，仅参考开发者与玩家社区公认的玩法原型做「可观察玩法」的常识性描述，凡涉及日期、规模的说法一律标「未核实」。后续若获得可用网络，可在返工时补充真实来源。

## 1. 玩法原型参考（非市场调研；来源=公认常识，未核实）

| 原型 | 可观察玩法（常识描述） | 对本项目的启示 |
| --- | --- | --- |
| 蓄力跳台（如「跳一跳」类，日期/数据未核实） | 按压蓄力、松手起跳，落点离台面中心越近得分越高，落空即败 | 单指操作、规则一句话可解释、灰盒最快验证手感 |
| 落球合成（如「合成大西瓜」类，日期/数据未核实） | 向容器投放物体，相同物体相碰升级合成，堆出界即败 | 连锁合成反馈强，但依赖 2D 物理调参与素材量 |
| 弹球破阵（如 Ballz 类，日期/数据未核实） | 拖动瞄准发射多球反弹，击碎带数字砖块，砖块推进触底即败 | 回答策略感强，但数值曲线与大量球体碰撞要反复调 |
| 层叠取物三消（如「羊了个羊」类，日期/数据未核实） | 从层叠牌堆取三张同款消除，卡槽满即败 | 被排除：乐趣依赖关卡设计量，内容成本对一人团队过高 |
| 点触躲避（Flappy 类，日期/数据未核实） | 单击维持飞行穿过缝隙 | 被排除：同质化最严重，差异空间最小 |

## 2. 三个候选

### 候选 A：蓄力跳台《节气跳跳》（暂定名）

- **一句话玩法**：按住屏幕蓄力、松手起跳，让小方块落到下一块「节气石」上；落点越靠中心得分越高，落空坠落即结束。
- **目标玩家**：全年龄碎片时间玩家；单手竖屏、无阅读门槛。
- **输入→反馈→奖励循环**：观察台距 → 按住蓄力（角色下蹲压缩、有蓄力音）→ 松手起跳（抛物线 + 挤压拉伸落地动画）→ 落点判定（Perfect 高音 + 轻振动；边缘踉跄动画）→ 分数上涨、连击加分。
- **复玩驱动**：冲击自己最高分；「差一点就 Perfect」的近失效应；连击里程碑的瞬时爽感。
- **失败/胜利规则**：无尽计分制。坠台即失败；单局「胜利」体验 = 打破个人纪录时的新纪录结算高光。单局约 30 秒–2 分钟。
- **内容成本**：极低。几何体 + 扁平色程序绘制即可作为正式风格；无关卡内容，台座由带种子随机生成。
- **技术风险**：低。纯几何 + 抛物线运动，不需要物理引擎；风险集中在蓄力-距离手感的调参（有明确参数表，见 game-design.md）。
- **潜在变现**（均需资格确认，未核实门槛）：激励视频「复活一次 / 本局双倍分」；无广告时功能整体隐藏，不阻塞。

### 候选 B：落球合成《瓜瓜满仓》（暂定名）

- **一句话玩法**：往容器里投放水果，相同水果相碰合成更大一级，堆出警戒线即失败，追求合成最大水果与高分。
- **目标玩家**：喜欢合成/消除类休闲玩法的全年龄玩家。
- **输入→反馈→奖励循环**：预览下一颗 → 横移选位 → 投放（物理滚动堆积）→ 相同相碰合成（升级特效 + 音效）→ 连锁合成追加奖励分。
- **复玩驱动**：冲击更高合成等级与分数；应对随机投放序列的策略选择。
- **失败/胜利规则**：无尽计分制，堆出警戒线即失败；「胜利」= 新纪录结算。
- **内容成本**：中低。需 10–11 级水果形象（可用几何+表情风格程序绘制），合成特效若干。
- **技术风险**：中。依赖 2D 物理引擎（Cocos 内置 Box2D）的堆叠稳定性与合成时序；挤出、卡墙、连锁误判等边界情况多，调参周期不可控。
- **潜在变现**：激励视频复活。

### 候选 C：弹球破阵《弹球破阵》（暂定名）

- **一句话玩法**：拖动瞄准发射一排小球，球反弹击碎带数字的砖块；砖块每回合下移一行，触底即失败。
- **目标玩家**：喜欢瞄准/弹道策略的休闲玩家，接受略高的认知门槛。
- **输入→反馈→奖励循环**：拖动瞄准（预测线反馈）→ 松手发射（多球反弹雨）→ 击碎砖块（碎裂特效 + 掉落加球道具）→ 回合结束砖块推进形成压迫。
- **复玩驱动**：冲击更高回合数；每回合随机砖阵的新鲜感。
- **失败/胜利规则**：回合制无尽，砖块触底即失败；「胜利」= 新纪录结算。
- **内容成本**：低。数字砖块纯程序绘制；道具 2–3 种。
- **技术风险**：中。一回合几十上百颗球的碰撞模拟需要性能与确定性保障；数值难度曲线需反复实测。
- **潜在变现**：激励视频（回合内加球 / 失败复活）。

## 3. 评分与推荐

评分均为 1–5 分，**5 = 对本项目（一人开发、首版可验证）最有利**。评分为设计判断，不是收入预测。

| 维度 | A 蓄力跳台 | B 落球合成 | C 弹球破阵 | 评分依据 |
| --- | --- | --- | --- | --- |
| 开发复杂度（5=最可控） | **5** | 3 | 3 | A 无物理引擎、规则最简；B/C 均有物理/碰撞调参风险 |
| 趣味验证成本（5=最快验证） | **5** | 4 | 3 | A 灰盒两天内可玩；B 需物理手感成立才可评判；C 需数值曲线成立 |
| 平台适配（5=最贴合竖屏单手短局） | **5** | 4 | 4 | A 单指按压最纯粹；B/C 需要瞄准/拖动的精度适配 |
| 素材成本（5=最低） | **5** | 3 | 4 | A 几何+配色即可；B 需 10+ 级形象；C 程序绘制即可 |
| 差异点（5=原创空间最大） | 2 | 3 | 3 | A 原型最经典、最易被视作换皮，需靠主题与手感差异化；B/C 有组合创新空间 |
| **总分** | **22** | 17 | 17 | — |

**推荐：候选 A《节气跳跳》。** 理由：

1. 技术风险最低、验证最快，最符合「一个人 + 首版必须可完成可验证」的硬约束；失败模式（B 物理调参失控、C 数值失控）都会拖垮进度。
2. 玩法一句话可解释，H2 试玩门禁能用最短路径回答「是否愿意再玩一局」。
3. 差异点分低的问题用**主题化 + 手感**对冲：台座以二十四节气命名、配扁平色带与程序绘制的季节意象；核心差异体验是「Perfect 连击」的判定阈值、动画与音效组合——手感是可以调参 Design 出来的差异，不依赖内容量。
4. 商业化不确定性（账号资质未提供）不阻塞它：无尽计分玩法无广告也是完整闭环，激励视频位只做预留接口。

## 4. 推荐方案边界（给 H1 的一页决策材料）

- **推荐方案**：候选 A《节气跳跳》（暂定名可改），竖屏、单指、1–3 分钟内单局、离线计分。
- **MVP 玩家可见功能：共 6 项**（MVP-F1～F6 明细见 `game-design.md` §12）：核心蓄力跳跃与落点判定、分数与本地最高分、Perfect 连击加分、首局三步教程、音效与振动开关、暂停/失败一键重开。
- **首版不做**：排行榜、皮肤与角色成长、每日任务/成就、广告与内购接入（仅预留接口）、背景音乐、多人/分享/云存档、横屏、剧情文案。完整清单 NOT-1～NOT-10 见 `game-design.md` §13。
- **资源预算**：外部支出 0 元；美术 = 程序绘制几何/扁平风（brief 允许作为正式风格）；引擎 Cocos Creator 3.8 LTS + TypeScript，补丁版本在 02-architecture 阶段实机锁定。
- **单局节奏**：目标中位数 30 秒–2 分钟，符合 brief 的 1–3 分钟上限。
- **给 H1 的三个确认问题**：
  1. 是否确认以候选 A 为唯一首版方案（B/C 备案留档）？
  2. 暂定名《节气跳跳》与二十四节气主题是否接受（不接受可换主题，不影响玩法与进度）？
  3. 账号/资质类事项（§5）确认由用户本人推进；确认这些事项**不阻塞**原型与后续开发排期。
